World Coordinate System

Takes the latest frame from every camera and chains poses from the world tag: cameras seeing it are placed directly; other tags seen by those cameras join the world, letting further cameras chain in. Anything with no path to the world tag is omitted. Drag to rotate, middle- or right-drag (or Ctrl-drag) to pan, scroll to zoom.

tag edges: X / Y from the origin corner · world tag · cameras drawn as frustums · units mm

Quickstart — calibration board

Print this ChArUco board and use it for camera calibration (and later for in-place pose estimation). Click the preview or the Print button, then print at 100% scale — turn off “fit to page” — and verify a few squares with a ruler afterwards.

Everything (boards and tags) uses one dictionary: AprilTag 36h11. The board consumes the lowest marker IDs; use IDs 100+ for object tags so the ranges never collide.

Individual object tags

Standalone 36h11 tags to print, cut out, and glue onto objects or infrastructure. Add tags to the sheet — the ID advances automatically, or set it manually before adding. Tag size includes the black border; keep the white quiet zone around each tag when cutting.
